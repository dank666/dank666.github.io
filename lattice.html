Concept Lattice Demo

Enter a formal context — a table of objects and the attributes they have — and watch its concept lattice being drawn. Three-way concepts add what a group of objects definitely lacks. A small teaching tool for the structures behind my research on formal concept analysis and the reliability of what large language models know.

输入一个形式背景（对象与属性组成的表格），实时画出它的概念格；切换到三支概念，还能看到一组对象“肯定不具有”哪些属性。这是一个小型的教学演示，展示我在形式概念分析与大语言模型知识可靠性研究中所依托的结构。

Geben Sie einen formalen Kontext ein – eine Tabelle aus Gegenständen und ihren Merkmalen – und sehen Sie zu, wie sein Begriffsverband gezeichnet wird. Drei-Wege-Begriffe zeigen zusätzlich, was einer Gruppe von Gegenständen mit Sicherheit fehlt. Ein kleines Lehrwerkzeug für die Strukturen hinter meiner Forschung zur Formalen Begriffsanalyse und zur Verlässlichkeit des Wissens großer Sprachmodelle.

A → B means: every object that has all of A also has all of B. Listed are the fewest rules from which every other rule of the table follows (its canonical basis). They describe the table itself, whichever kind of concept is drawn. A → B 表示：凡是具有 A 中全部属性的对象，也都具有 B 中的全部属性。这里列出的是能推出表中其余所有规则的最少一组规则（规范基）。它们描述的是表格本身，与当前画的是哪种概念无关。 A → B bedeutet: Jeder Gegenstand, der alle Merkmale aus A hat, hat auch alle aus B. Aufgeführt ist die kleinste Menge von Regeln, aus der alle übrigen Regeln der Tabelle folgen (ihre kanonische Basis). Sie beschreiben die Tabelle selbst, gleich welche Art von Begriff gezeichnet wird.

Definition定义Definition

Classical concept (X, Y): X is a set of objects, Y is the set of attributes that all of them share, and X is exactly the set of objects having all of Y. Concepts are ordered by inclusion of their extents X; the result is the concept lattice (top = all objects). 经典概念 (X, Y)：X 是对象集合，Y 是这些对象全部共有的属性，并且 X 恰好是拥有 Y 中所有属性的对象集合。概念按外延 X 的包含关系排序，得到概念格（最上面是包含全部对象的概念）。 Klassischer Begriff (X, Y): X ist eine Menge von Gegenständen, Y ist die Menge der Merkmale, die sie alle gemeinsam haben, und X ist genau die Menge der Gegenstände, die alle Merkmale aus Y haben. Begriffe werden nach der Inklusion ihrer Umfänge X geordnet; das Ergebnis ist der Begriffsverband (oben = alle Gegenstände).

Three-way concept (X, (Y, Z)): Y is the set of attributes that every object in X has, Z is the set of attributes that no object in X has, and X is exactly the set of objects having all of Y and none of Z. It records what the objects do have and what they definitely lack (shown as ¬attribute). 三支概念 (X, (Y, Z))：Y 是 X 中每个对象都具有的属性，Z 是 X 中所有对象都不具有的属性，并且 X 恰好是具有 Y 中全部属性、且不具有 Z 中任何属性的对象集合。它既记录对象“有什么”，也记录“肯定没有什么”（图中以 ¬属性 表示）。 Drei-Wege-Begriff (X, (Y, Z)): Y ist die Menge der Merkmale, die jeder Gegenstand in X hat, Z ist die Menge der Merkmale, die kein Gegenstand in X hat, und X ist genau die Menge der Gegenstände, die alle Merkmale aus Y und keines aus Z haben. Er hält fest, was die Gegenstände haben und was ihnen mit Sicherheit fehlt (dargestellt als ¬Merkmal).

Attribute-induced three-way concept (Y, (X, W)): the dual view. Y is a set of attributes, X is the set of objects having all of them, W is the set of objects having none of them, and Y is exactly the set of attributes that all of X have and none of W has. Here the nodes are sets of attributes. 属性诱导的三支概念 (Y, (X, W))：对偶视角。Y 是属性集合，X 是拥有 Y 中全部属性的对象，W 是不拥有 Y 中任何属性的对象，并且 Y 恰好是 X 中所有对象都具有、且 W 中所有对象都不具有的属性集合。此时节点是属性的集合。 Merkmalsinduzierter Drei-Wege-Begriff (Y, (X, W)): die duale Sicht. Y ist eine Menge von Merkmalen, X ist die Menge der Gegenstände, die sie alle haben, W ist die Menge der Gegenstände, die keines davon haben, und Y ist genau die Menge der Merkmale, die alle Gegenstände aus X und keiner aus W haben. Hier sind die Knoten Mengen von Merkmalen.

Reading the diagram. A name written above a node also holds for every node below it; a name written under a node also belongs to every node above it. The upper half of a node is filled where a name is written above it, the lower half where one is written under it. 读图方法。写在节点上方的名称，对它下方的所有节点也成立；写在节点下方的名称，也属于它上方的所有节点。节点上半部分填色，表示它上方标有名称；下半部分填色，表示它下方标有名称。 So liest man das Diagramm. Ein Name über einem Knoten gilt auch für alle Knoten darunter; ein Name unter einem Knoten gehört auch zu allen Knoten darüber. Die obere Hälfte eines Knotens ist gefüllt, wo ein Name über ihm steht, die untere, wo einer unter ihm steht.

Notation and naming differ between papers; this page uses the common formulation in which the three-way concepts are the concepts of the table extended with a negated copy of every attribute. 不同论文的记号和叫法略有差异；本页采用的是常见的表述：三支概念等价于在表格中为每个属性增加一个“否定”副本之后得到的概念。 Notation und Benennung unterscheiden sich von Artikel zu Artikel; diese Seite verwendet die verbreitete Formulierung, nach der die Drei-Wege-Begriffe die Begriffe der Tabelle sind, die um eine negierte Kopie jedes Merkmals erweitert wurde.
