Concept Lattice Demo

Enter a formal context — a table of objects and the attributes they have — and watch its concept lattice being drawn. Switch to three-way concepts to see, in addition, which attributes a group of objects definitely lacks. It is a small teaching tool for the kind of structure behind my research on concept learning and three-way concept analysis.

输入一个形式背景（对象与属性组成的表格），实时画出它的概念格。切换到三支概念，还能看到一组对象“肯定不具有”哪些属性。这是一个小型的教学演示，展示的正是我研究概念学习与三支概念分析时所依托的结构。

Concept lattice概念格

Classical concept (X, Y): X is a set of objects, Y is the set of attributes that all of them share, and X is exactly the set of objects having all of Y. Concepts are ordered by inclusion of their extents X; the result is the concept lattice (top = all objects). 经典概念 (X, Y)：X 是对象集合，Y 是这些对象全部共有的属性，并且 X 恰好是拥有 Y 中所有属性的对象集合。概念按外延 X 的包含关系排序，得到概念格（最上面是包含全部对象的概念）。

Three-way concept (X, (Y, Z)): Y is the set of attributes that every object in X has, Z is the set of attributes that no object in X has, and X is exactly the set of objects having all of Y and none of Z. It records what the objects do have and what they definitely lack (shown as ¬attribute). 三支概念 (X, (Y, Z))：Y 是 X 中每个对象都具有的属性，Z 是 X 中所有对象都不具有的属性，并且 X 恰好是具有 Y 中全部属性、且不具有 Z 中任何属性的对象集合。它既记录对象“有什么”，也记录“肯定没有什么”（图中以 ¬属性 表示）。

Attribute-induced three-way concept (Y, (X, W)): the dual view. Y is a set of attributes, X is the set of objects having all of them, W is the set of objects having none of them, and Y is exactly the set of attributes that all of X have and none of W has. Here the nodes are sets of attributes. 属性诱导的三支概念 (Y, (X, W))：对偶视角。Y 是属性集合，X 是拥有 Y 中全部属性的对象，W 是不拥有 Y 中任何属性的对象，并且 Y 恰好是 X 中所有对象都具有、且 W 中所有对象都不具有的属性集合。此时节点是属性的集合。

Notation and naming differ between papers; this page uses the common formulation in which the three-way concepts are the concepts of the table extended with a negated copy of every attribute. 不同论文的记号和叫法略有差异；本页采用的是常见的表述：三支概念等价于在表格中为每个属性增加一个“否定”副本之后得到的概念。
